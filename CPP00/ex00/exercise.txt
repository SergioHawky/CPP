CPP00 - ex00: megaphone
========================

Goal:
Write a program that takes command-line arguments and prints them in UPPERCASE,
separated by spaces. If no arguments are provided, it prints a default noise
message.

Files:
  - src/megaphone.cpp
  - Makefile

How it works:
  - If argc < 2 (no arguments), prints "* LOUD AND UNBEARABLE FEEDBACK NOISE *"
  - Otherwise, iterates over each argument, converts every character to
    uppercase using toupper(), and prints them separated by spaces.
  - Compiled with c++98, -Wall -Wextra -Werror.

Build:
  make        -> produces the megaphone binary
  ./megaphone "Hello World"  -> prints "HELLO WORLD "
  ./megaphone                -> prints the noise message

C vs C++ — Key Differences for Beginners
==========================================

1. File extension
   - C:  .c
   - C++: .cpp (source), .hpp (headers, though .h also works)

2. I/O (Input / Output)
   - C:  printf / scanf  (from <stdio.h>)
   - C++: std::cout << "text"   (output)
          std::cin  >> var      (input)
          std::getline(std::cin, str)  (full line input)
     All from <iostream> (no .h)
   - C++ uses "streams" (<< and >> operators) instead of format strings.

3. Strings
   - C:  char* / char[] + <string.h> (strlen, strcpy, etc.)
   - C++: std::string  from <string>
          - automatic memory management
          - can use + for concatenation, .length(), .substr(), etc.
          - much safer and easier

4. Memory allocation
   - C:  malloc / free
   - C++: new / delete  (and new[] / delete[] for arrays)
          - calls constructors/destructors automatically

5. Classes & objects (the big one)
   - C is procedural — you have structs with only data.
   - C++ has classes: you group data AND functions together.
     Encapsulation: private (internal) vs public (external) members.
     Constructors: special functions called when an object is created.

6. References
   - C has only pointers (*).
   - C++ adds references (&) — like a pointer but cannot be NULL,
     cannot be reassigned, and no need to dereference with *.

7. Namespaces
   - C has a flat namespace (risk of name clashes).
   - C++ has namespaces: std::cout means "cout from the std namespace".
     You can also write "using namespace std;" to avoid typing std::,
     but it's bad practice in headers.

8. Function overloading
   - C:  only one function per name.
   - C++: you can have multiple functions with the same name but different
          parameters (overloading).

9. The "standard" in this course
   - All exercises compile with -std=c++98 -Wall -Wextra -Werror
   - C++98 is an old standard; no auto, no range-based for, no nullptr
     (use NULL or 0), no smart pointers.
   - Modern C++ (C++11/14/17/20) has many more features, but 42's curriculum
     enforces C++98 for these early modules.

Quick example (C vs C++):

  // C
  #include <stdio.h>
  #include <string.h>
  int main() {
      char name[100];
      printf("Name: ");
      scanf("%s", name);
      printf("Hello %s\n", name);
      return 0;
  }

  // C++
  #include <iostream>
  #include <string>
  int main() {
      std::string name;
      std::cout << "Name: ";
      std::getline(std::cin, name);
      std::cout << "Hello " << name << std::endl;
      return 0;
  }
